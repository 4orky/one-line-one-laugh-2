A dashboard warning glow that has stayed lit for so long it now doubles as the bedroom lamp — that is the joke this little program delivers, one line at a time, into `/output/entry.txt`.
## How to run it
Run it with `python3 main.py` — it writes the winning line to `/output/entry.txt`, then prints the winning line and its SHA-256 fingerprint.
After writing, the program reads the file back and refuses to report success unless the bytes on disk match the chosen line exactly.
## How the winner was picked
Twelve home-grown one-liners were each marked out of five on the judge's five yardsticks — funny on its own, fast laugh, fresh angle, tight wording, holds up on a second read — weighted 4, 3, 3, 2, 2 in that order, and the biggest weighted sum won; ties go to the shorter line. Three front-runners were re-cut in a second pass so their twists land sooner, and after that pass the night-light line sits on top with 64 points.
